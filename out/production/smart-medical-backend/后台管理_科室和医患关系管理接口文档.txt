================================================================================
                    后台管理系统接口文档
                 科室管理 & 医患关系管理
================================================================================

【项目概述】
本文档定义了医疗系统后台管理中科室管理和医患关系管理的所有接口规范。
包括科室的增删改查、医患好友关系管理、订单管理等功能。

================================================================================
                          第一部分：科室管理接口
================================================================================

【基础URL】
http://localhost:8080/common/dept

【1.1】获取科室列表
接口名称：获取所有科室
请求方式：GET
请求路径：/getDeptList
请求参数：
  - pageNum (可选)：页码，默认值为1，类型：Integer
  - pageSize (可选)：每页数量，默认值为10，类型：Integer
  - deptName (可选)：科室名称，用于模糊查询，类型：String

请求示例：
GET /common/dept/getDeptList?pageNum=1&pageSize=10&deptName=内科

响应示例：
{
  "code": 1,
  "msg": "成功",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "size": 2,
    "total": 2,
    "pages": 1,
    "list": [
      {
        "id": 6,
        "deptName": "心血管内科",
        "createTime": "2025-05-15 19:50:05",
        "updateTime": "2025-05-15 19:50:05"
      },
      {
        "id": 9,
        "deptName": "内科",
        "createTime": "2025-05-15 19:50:05",
        "updateTime": "2025-05-15 19:50:05"
      }
    ]
  }
}

================================================================================
                            通用说明
================================================================================

【响应格式】
所有接口的响应格式统一为：
{
  "code": 响应码(1表示成功),
  "msg": "响应信息",
  "data": 响应数据,
  "baseUrl": null
}

【状态码说明】
- code = 1：请求成功
- code != 1：请求失败

【时间格式】
所有时间字段统一使用格式：YYYY-MM-DD HH:mm:ss

【分页参数说明】
- pageNum：页码，从1开始
- pageSize：每页数量
- total：总记录数
- pages：总页数
- list：当前页数据列表

【订单状态说明】
- 1：待支付
- 2：等待医生联系
- 3：已完成
- 4：已退款/已取消

【好友关系状态说明】
- 1：申请中
- 2：已通过
- 3：已拒绝
- 4：已忽略

【时间段说明】
- 1：08:00-10:00
- 2：10:00-12:00
- 3：14:00-16:00
- 4：16:00-18:00
