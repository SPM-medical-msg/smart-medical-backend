================================================================================
                    前台患者系统接口文档
            患者对话框、咨询订单、诊断方案

【项目概述】
本文档定义了医疗系统前台患者端的对话框、订单咨询、诊断方案等功能的接口规范。
包括患者与医生的聊天、订单查询、诊断方案查看等功能。

================================================================================
                            通用说明
================================================================================

【响应格式】
所有接口的响应格式统一为：
{
  "code": 响应码(1表示成功),
  "msg": "响应信息",
  "data": 响应数据,
  "baseUrl": null
}

【状态码说明】
- code = 1：请求成功
- code != 1：请求失败

【时间格式】
所有时间字段统一使用格式：YYYY-MM-DD HH:mm:ss

【分页参数说明】
- pageNum：页码，从1开始
- pageSize：每页数量
- total：总记录数
- pages：总页数
- list：当前页数据列表

【订单状态说明】
- 1：待支付
- 2：等待医生联系
- 3：已完成
- 4：已退款/已取消

【消息类型说明】
- 1：文本消息
- 99：系统消息（如"患者已结束咨询"）

【消息查看状态说明】
- 1：未查看
- 2：已查看

【时间段说明】
- 1：08:00-10:00
- 2：10:00-12:00
- 3：14:00-16:00
- 4：16:00-18:00

【好友关系状态说明】
- 1：申请中
- 2：已通过（已成为好友）
- 3：已拒绝
- 4：已忽略

【使用流程示例】

1. 患者查看医生列表并选择医生
2. 患者提出咨询申请 → POST /common/friend/saveFriendInfo
3. 医生同意申请（后台处理）
4. 患者创建订单 → POST /common/order/saveOrderInfo
5. 患者支付订单 → POST /common/order/payOrderInfo
