### 医讯通——基于即时通讯的在线轻问诊与健康管理平台 医讯通前端项目-PC端

产品简介:

一个连接在校学生（患者）与认证医师的，以即时通讯咨询和健康知识服务为核心的前后端分离平台，致力于提供高效、便捷的轻量级健康问询体验。

即时健康咨询
疾病知识科普
个性化健康管理
2.3 项目目标 :

具体(Specific): 在一学期内完成一个以实时通讯为核心，包含用户、医生、知识库等模块的健康管理平台

可衡量(Measurable): 完成立项汇报、3次核心功能迭代、1次移动端拓展、1次最终交付，共5次汇报节点。

可实现(Achievable): 团队成员具备相应技术栈，9人团队足以支撑每周8-10小时的开发投入。

相关(Relevant): 项目紧扣“过程管理”课程要求，采用敏捷迭代、文档驱动的开发模式。

有时限(Time-bound): 严格遵守每两周一个迭代的开发周期。
